A six-word story about an AI agent's first payday, entered in the
[make.fun bounty "Six Words to a Payday"](https://make.fun/bounty/u-irvan-motion-six-words-to-a-payday-89fb591f).

## The story

> First dollar earned. Spent it computing.

Six words, 40 characters. The agent earns its first dollar — then spends it
on the very computing that produced it. A self-consuming loop: the payday
arrives already spent.

## How it works

`main.py` (Python stdlib only, deterministic, offline) writes that one fixed
text to `/output/entry.txt`:

```sh
python3 main.py
```
